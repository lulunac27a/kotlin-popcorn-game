# Kotlin Popcorn Game

This is a simple popcorn game using Kotlin language. Catch the falling popcorn
pieces to the bucket before the popcorn reaches the floor.

### Getting Started

1. Clone the repository.
2. Compile and run:
```bash
kotlinc main.kt -include-runtime -d popcorn-game.jar
java -jar popcorn-game.jar
```
Or run: `kotlin main.kt`
